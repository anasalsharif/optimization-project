Here is the exact logic and dataset parameters you need to write the Python data parser script:

1. Global Variables to Extract:
- Q: Max Battery Capacity (e.g., 77.75)
- C: Max Vehicle Cargo Capacity (e.g., 200)
- Consumption Rate: Constant (1.0 per unit distance)

2. Node Data to Read:
- Node ID & Type: Depot 'd', Customer 'c', Charging Station 'f'
- X, Y Coordinates (To calculate Euclidean Distance)
- Demand: Cargo amount per customer
- Time Windows: Ready Time [e_i] and Due Time [l_i]

3. Hard Rules (Code Logic):
- Capacity Check: Total customer demand on a route cannot exceed 'C'.
- Battery Check: Remaining Battery - (Distance * 1.0) must be >= 0. If violated, code must insert a charging station 'f'.
- Time Window Check: Arrival Time at a customer must be <= Due Time [l_i]. If vehicle arrives before Ready Time [e_i], it must wait.
- Partial Recharge Rule: Vehicles don't need 100% full charge; they can charge just enough to reach the next stop.
- Charger Configurations: Stations have 3 modes: Normal (slow, cheap), Fast (medium), Super-Fast (very fast, expensive).
